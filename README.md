# Digital Forensics Pro — التحليل الجنائي الرقمي

مشروع C# WinForms متوافق مع Windows 11 و.NET 10، ومصمم بأسلوب لوحة تحكم عربية داكنة مشابهة للواجهات المرفقة.

## المزايا
- إدارة قضية: رقم القضية، الاسم، الفاحص والوصف.
- مستودع الأدلة: إضافة عدة ملفات.
- حساب SHA-256 تلقائياً عند إضافة الدليل.
- التحقق من سلامة الأدلة بإعادة حساب SHA-256.
- تحليل بيانات الملف الأساسية.
- محلل SHA-256 لملف منفرد.
- جدول زمني للأدلة.
- إنشاء وتصدير تقرير نصي.
- واجهة عربية RTL وتصميم Dashboard.

## التشغيل في Visual Studio 2026
1. فك الضغط.
2. افتح `DigitalForensicsPro.sln`.
3. تأكد من تثبيت `.NET 10 SDK` وDesktop development with .NET.
4. اجعل `DigitalForensicsPro` مشروع بدء التشغيل.
5. اضغط `F5`.

> ملاحظة: المشروع تعليمي/جامعي. في التحقيقات الحقيقية يجب استخدام نسخ جنائية وأدوات معتمدة وإجراءات حفظ الأدلة وسلسلة الحيازة.
